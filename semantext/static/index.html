New environment

A set of rules for one context, such as Office, Studying or Late night. Every agent reads the active one.

    Edit the file

    The language

    statement
    The rule in plain words. This is what your AI reads.
    applies_when
    When it matters, in plain words.
    enabled
    On or off, without deleting it.
    always
    On every card, even the short one.
    relay
    Also on the short card, for words that are not yours.
    provenance
    Where it came from, with your own words kept beside it.
    agents
    Each agent's own rules, under its name.

    Saving checks the file first, and the old version is always kept.
